# Logotipo de El Alazán

Guarda aquí el archivo del logotipo con el nombre exacto:

```
assets/branding/logo.png
```

(formato PNG, idealmente cuadrado, fondo incluido o transparente).

La app lo detecta sola: mientras no exista, muestra un monograma dorado
con el estilo de la marca. Para el icono del programa (ventana/escritorio)
se usa `flutter_launcher_icons` — pedírselo al asistente cuando el PNG
ya esté en esta carpeta.
